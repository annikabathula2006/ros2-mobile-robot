# ROS 2 Mobile Robot Simulation

A mobile robotics project developed using ROS 2 Jazzy, Ubuntu 24.04, and Gazebo.

## Project Overview

This project aims to develop and simulate a mobile robot using ROS 2 and Gazebo. It will demonstrate robot modelling, simulation, sensor integration, and mobile robot control.

## Technologies

- Ubuntu 24.04 LTS
- ROS 2 Jazzy
- Gazebo Sim
- Python
- URDF / Xacro
- Git and GitHub

## Project Structure

- config/
- description/
- launch/
- meshes/
- screenshots/
- worlds/

## Planned Features

- Mobile robot modelling
- Gazebo simulation
- Robot description using URDF/Xacro
- ROS 2 launch files
- Robot movement and control
- Simulation screenshots and documentation
